# Pendrop Penpot Plugin

Penpot plugin for mapping component data to Drupal entities. Enables configuration of entity mappings, view configurations, and component definitions directly within Penpot.

## Overview

The plugin provides a user interface within Penpot to map design components to Drupal content types, configure views, and define component properties including variants, slots, props, and Storybook stories.

## Features

- Entity mapping configuration
- View configuration
- Component definition with variants, slots, props, and stories
- Integration with Pendrop workflow

## Development

```bash
npm install
npm run dev
```
